# Audit ledger

Code defects and structural problems found by inspection. Append-only; a fixed
entry keeps its history and records the verification command.

**Method:** read the sources and ran the baseline (`cargo test --locked
--workspace --all-targets` → 51 passed; `cargo clippy … -D warnings` clean;
`cargo fmt --check` clean). The Android APK and the Swift package were **not**
rebuilt, so platform findings are by inspection, not by execution.

| ID | Severity | Status | Location | Defect | Fix |
| --- | --- | --- | --- | --- | --- |
| A-001 | high | open | `core/src/protocol.rs` vs `experiments/.../Signaling.kt`, `apps/mac-native/.../MacController.swift` | The 1,900-line binary codec is not used on the wire; both platform slices speak newline JSON over TLS. The codec, its 16 message kinds, and its tests are a parallel protocol universe. | Either delete the legacy codec or make the control plane encode with it. Pick one before adding messages. |
| A-002 | high | open | `core/src/protocol.rs` `Hello { device_id: u64 }` vs `core/src/control_plane.rs` `DeviceFingerprint([u8;32])` | Two incompatible identity models. A 32-byte public-key fingerprint cannot be represented by a `u64`. | Version the binary protocol and carry the fingerprint, or retire the legacy `DeviceId` from the wire. |
| A-003 | medium | open | `core/src/session.rs` (`SessionConfig::default`) vs `core/src/control_plane.rs` (`HEARTBEAT_INTERVAL_MS`, `DEGRADE_AFTER_MS`, `LOSE_AFTER_MS`) | Two lifecycle models with contradictory timers (30 s/15 s/5 min versus 1 s/3 s/6 s) and no arbitration between them. | Make `LinkMachine` the only lifecycle owner; keep `SessionManager` as a pure record store or remove it. |
| A-004 | high | open | `experiments/.../PairingProtocol.kt` (`reconnect`), `ContinuityService.kt`, `app/src/main/cpp/idroid_core_jni.cpp` | A fresh `NativeCoreLink` is created and closed per reconnect, so resume metrics and `SessionChanged` never run; `session_id` is `SystemClock.elapsedRealtime()`; the JNI shim hardcodes `has_session = true`. | One machine per service lifetime; mint and persist a real session id; pass `has_session` from actual state. |
| A-005 | high | open | whole repo | No cross-language contract tests. Kotlin, Swift and Rust each implement the exchange independently; no golden vectors are shared. | Emit golden frames/fixtures from Rust and consume them in Kotlin and Swift tests, or add an `xtask` that round-trips. |
| A-006 | medium | open | `apps/mac-native/Sources/IdroidMac/IdentityStore.swift:~102` | Device identity is generated by shelling out to `/usr/bin/openssl` and parsing output. macOS ships LibreSSL; `Process` is awkward under sandbox/notarization. | `SecKeyCreateRandomKey` + `SecKeyCreateSignature`, key in Keychain with `…AfterFirstUnlockThisDeviceOnly`. |
| A-007 | high | open | `apps/mac-native/` (`build-mac.sh`, `Sources/`) | No `.app` bundle, Info.plist, or entitlements exist. There is nowhere to declare `NSLocalNetworkUsageDescription`, `NSBonjourServices`, or `NSBluetoothAlwaysUsageDescription`. | Generate a minimal bundle in the build script; sign with entitlements. See `F-030`. |
| A-008 | high | open | `experiments/.../ContinuityService.kt` (`startTransport`) | `accept()` throwing exits the loop; `server` is non-null, so `onStartCommand` never restarts and `START_STICKY` redelivers to a dead object. | A-009 | high | open | `experiments/.../NsdDiscovery.kt` | Advertises and browses the same `_acontinuity._tcp` type, filters itself by service *name*, fires a reconnect for every found peer, and uses the deprecated single-flight `resolveService`. | Filter by TXT `id`/`role`; dedupe; serialize resolves with a timeout; `registerServiceInfoCallback` on API 34+. | A-010 | high | open | `experiments/.../` (no `ConnectivityManager` usage) | No network-change handling anywhere. | A-011 | medium | open | `experiments/.../ContinuityService.kt` (`handle`) | Every accepted socket calls `networkChanged → beginConnecting → transportConnected → handshakeReady` with one timestamp, forcing `Ready→Degraded→Searching` regardless of state. | Drive transitions from observed state; treat `InvalidTransition` as ignorable. |
| A-012 | medium | open | `core/src/connections.rs`, `apps/mac-native/.../MacController.swift` | `ConnectionArbiter` exists for simultaneous dials but only the Mac calls it; Android never arbitrates. | Call it on both sides, and suppress duplicate discovery within ~500 ms. |
| A-013 | medium | open | `apps/mac-native/.../MacController.swift` (`handlePair`) | The one-time pairing token is a bearer secret compared with `==` (variable time), and there is no SAS confirmation. | Compare SHA-256 digests or use a constant-time compare; add a 6-digit SAS derived from sorted fingerprints plus the TLS exporter. |
| A-014 | low | fixed | `rust-toolchain.toml` vs local `PATH` | The pin says 1.85.0, but this machine's `rustc` is 1.99.1 (Homebrew), so `make test` validates a different compiler than CI. | Fixed: the Makefile now prefers the rustup toolchain selected by `rust-toolchain.toml`, and `make check-toolchain` fails on a version mismatch. | A-015 | medium | fixed | working tree | 1,209 lines of Instagram Export module added by `6d9ad5b` were deleted but uncommitted; manifest, gradle and `MainActivity` were modified accordingly. | Fixed: removal committed as `ebdcace`; no dangling references remain (`grep -R` for the module names). |
| A-016 | low | open | repository root | No `LICENSE`, no `SECURITY.md`, despite a threat model and a public-facing README. | `SECURITY.md` added with a GitHub private-advisory channel; `LICENSE` still needs an owner decision (not guessed). |
| A-017 | medium | open | `core/src/protocol.rs` (`ProtocolMessage::decode`) | Decoding requires a complete, exact frame; there is no incremental stream reader, so a real transport cannot use the codec without its own framing. | Add a bounded `FrameReader` that buffers and yields frames; fuzz it. |
| A-018 | medium | open | `core/src/protocol.rs` | No fuzzing or property tests on `decode`, which has 16 kinds and several variable-length fields. Hand-written unit tests cannot cover the input space. | `cargo-fuzz` or `proptest` target: arbitrary bytes must never panic and must never accept trailing data. |
| A-019 | low | open | `core/src/discovery.rs`, `pairing.rs`, `connections.rs` | Four abstractions (CandidateSource, PairingStore, DiscoveryRace, ConnectionArbiter) and ~1,800 lines for a two-device QR handshake. | Consider collapsing to Discover → Pair → Link; keep the tests as the contract. |
| A-020 | low | open | `apps/mac-tauri/` | Directory contains only a README; it is a scope marker, not code. | Remove it, or state in the root README that it is a placeholder. |

## Notes

- **A-001 is the load-bearing one.** Until the core codec is on the wire, every
  claim about "the protocol" is a claim about tests, not about the product.
- **A-004 + A-008 + A-010 are one failure mode** seen from three angles: the
  Android side has no supervisor. Fixing them together is cheaper than three
  separate patches.
- **A-007 blocks any TCC work.** Entitlements and usage descriptions cannot be
  declared without a bundle, so it comes before Screen Recording, Bluetooth, or
  microphone work.
